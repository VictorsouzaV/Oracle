# Oracle SQL

Repositório de estudos de **Oracle Database**, com anotações, comandos e exercícios práticos de SQL.

## Objetivo
Consolidar os fundamentos de SQL e PL/SQL no Oracle por meio de prática constante, com foco em consultas e manipulação de dados e lógica procedural.

## Conteúdos abordados
- SQL: consultas, filtros, manipulação de dados
- PL/SQL: estruturas condicionais (IF/ELSE), laços  (FOR, WHILE)
- Tratamento de exceções (EXCEPTION)
- Cursores (CURSOR, OPEN, FETCH, CLOSE, ROWTYPE)

## Ferramentas
- Oracle FreeSQL

## Estrutura
- exercicios/ #departamento, exception, for, if-else, while
-  anotacoes/ #comandos
